# Starlight Plugin

Expert guide for building and deploying static documentation sites with
[Astro Starlight](https://starlight.astro.build/). Covers project scaffolding, sidebar configuration, MDX components,
i18n, versioned docs, custom theming, and deployment to GitHub Pages or Cloudflare Pages. Includes migration guides
for VuePress, Docusaurus, MkDocs, and GitBook.
